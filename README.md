Twin Tides — a spot-the-difference game. Two near-identical hand-drawn scenes side by side, 24 differences hiding across three scenes (Harbor Morning, Night Market, Moon Garden), a countdown, hints, combos and a score to chase. Click either picture — or play by keyboard alone.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
